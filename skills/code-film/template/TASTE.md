# Taste

Rules for this film, written from review notes. Read before every change. When a note comes in, add the rule it implies, phrased so it applies to the next scene too, with the note that caused it.

## Color and type

- Never invent a color. Every color comes from `src/brand.ts`; if one is missing, ask, don't add it. (note: "never invent a color")

## Motion

- UI motion should look like a person using the product: a click is a short press and release, not a bounce. (note: "this feels like someone clicking a button")

## Sound

- No whooshes. Sound comes from things that happen on screen: keys, ticks, taps. (note: "no whooshes")
